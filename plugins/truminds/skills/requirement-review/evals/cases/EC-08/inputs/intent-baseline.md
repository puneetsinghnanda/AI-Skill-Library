# Intent baseline {#intent-baseline}

## Goals {#goals}
Every support ticket gets a first response and a clear owner.

## Constraints {#constraints}
Tickets have a priority from 1 (highest) to 4.
Response targets are measured from ticket creation.

## Priorities {#priorities}
Priority-1 tickets block a customer's work. Priority-4 tickets are questions.
