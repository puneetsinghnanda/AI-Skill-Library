# Glossary {#glossary}

## Order {#order}
A purchase placed by a customer. It has one current status.

## Order status {#order-status}
One of placed, packed, shipped, delivered or cancelled.

## Order history {#order-history}
The list of status changes of one order, with the time of each change.

## Shipment {#shipment}
The parcel that carries an order to the customer.
