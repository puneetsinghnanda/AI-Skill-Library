## Notes

- AI min: the attempt's time less the engineer's wait (D1 `active_ms`). Where the wait was not recorded (`n/r`, all runs before B2 and D1) it is the attempt's wall time, questions included, so `req` and `design` read high.
- Tokens: the step attempts' tokens, from D1 metrics in the run record or a `tsl state show --metrics --json` export in `benchmarks/metrics/` (tokens only). The run loop's own tokens (between attempts) are not in them: they are in Run loop out, known only from an export. Tokens in = input + cache read + cache write. A step median over fewer runs than the group says how many. `n/r`: not recorded.
- A retry is an attempt with cause `retry_*` (it uses retry budget). Reruns for other causes (answers, stale inputs, repin) are not counted as retries.
- OS is read from the paths in each run's tool log unless the set gives one. Wall min is run created to last update.
