# ABC-158 Allow cancelling an order before it ships

As a user I want to cancel an order that has not shipped yet, so that a mistaken order
does not go out.

Acceptance:
- An order can be cancelled while it is PLACED or PACKED.
- A cancelled order cannot change status again.
- Cancelling adds an entry to the status history.
- Orders that have shipped cannot be cancelled, including old orders stored as SHIPPD.

Notes:
The ticket does not say who may cancel: the customer, a support agent, or both.
