# ABC-163 Export a customer's orders as CSV

As a support agent I want to download one customer's orders as a CSV file, so that I can
answer billing questions offline.

Acceptance:
- A new endpoint returns one customer's orders as CSV.
- Columns: order id, created at, status, total in cents.
- The export can be sorted with the same sort options as order history.
- Archived orders are not included.
- The file name contains the customer code, never the customer's name or email.
