# Intent baseline {#intent-baseline}

## Goals {#goals}
Customers and support staff can see where orders are and what has changed.

## Constraints {#constraints}
Lists show 20 items per page, newest first. Money is integer cents.
Sources: sample-system:docs/REQUIREMENTS.md#L9, sample-system:docs/REQUIREMENTS.md#L19

## Order history {#order-history}
Order history shows the last 7 days by default. Recent activity on the order page covers
the last 30 days.
Sources: sample-system:docs/REQUIREMENTS.md#L10-L11
