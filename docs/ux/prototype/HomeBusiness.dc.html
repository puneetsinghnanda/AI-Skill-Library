How it is built

What is inside the library

Four building blocks. Engineers use them in Claude Code; everyone can browse them here.

Skills

One small, reusable AI capability, such as requirement review or unit tests. Works for any technology.

Workflows

Skills chained in order with human gates, for example requirement, design, code, tests, pull request.

Pods

Ready-made AI-augmented teams, for example a Solution Architect, a Full-stack developer and a QA agent with their workflows.

Quality harness

Checks every output against the client system, scores confidence and stops for a person when needed.
